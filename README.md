# Advanced Programming Lab File - Karnika,  240050

## 📌 Overview

This repository contains solutions to a comprehensive set of Java programming lab questions (Q1–Q22). The programs cover fundamental to intermediate concepts of Java, including:

* Object-Oriented Programming (OOP)
* Arrays and Matrix Operations
* Multithreading
* Exception Handling
* File Handling
* Swing (GUI Programming)
* JDBC (Database Connectivity)
* Packages and Inheritance

These programs are designed for **B.Tech (CSE) practical/lab work** and are written in a simple, exam-friendly format.

> 📝 *Note: Along with the listed questions, a few additional classwork files have also been included in this repository for extra practice and reference.*

## ▶️ How to Run

1. Install Java (JDK 8+)
2. Compile the program:

   ```bash
   javac FileName.java
   ```
3. Run the program:

   ```bash
   java FileName
   ```

> ⚠️ Note: For JDBC programs, ensure database connection details are correctly configured.
